# M5b — Widget Breadth + Gallery + Automation Actions: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Parallelism note (read before dispatching waves).** M5b is one long spine followed by a three-way fan-out:
> - **Spine (strictly sequential): Task 1 → Task 2 → Task 3 → Task 4 → Task 5.** Tasks 1–2 build the protocol vocabulary + the full codegen/schema surface; Tasks 3–4 both rewire `src/tree.zig` + `src/gtk_backend.zig` (events, then containers) and MUST NOT run concurrently; Task 5 rewires the React runtime and depends on the generated TS from Task 2 and the event wire from Task 3.
> - **Fan-out after Task 5 (disjoint files, safe in parallel):**
>   - **Task 6 — conformance track:** `src/null_backend.zig`, `src/conformance.zig` only.
>   - **Task 7 — automation-actions track:** `src/automation.zig` only.
>   - **Task 8 — gallery track:** `examples/gallery/*` (+ possibly root `package.json` workspace glob check) only.
> - **Task 9 (drive script + headless script + CI) depends on Tasks 7 AND 8. Task 10 (full gate + self-review) runs last.**
>
> Styling (`style` prop + web-CSS rejection) and ListView-with-recycling are **M5c** — explicitly NOT in this plan. Do not add them.

**Goal:** Grow the schema from 4 widgets to 18 (spec §6 v1 core set minus ListView/Menu, plus a WebView stub), all through the M5a codegen mandate (D6): every new widget is a `schema/widgets.json` entry plus codegen templates — zero hand-written per-widget bindings. Land the full **semantic input model** (spec §8): native change signals flow up as typed NDP Events (`changed`/`activate`/`toggled`/`valueChanged`/`selectionChanged`); React handler props (`onChanged`, `onToggled`, …) receive typed payloads; two-way widgets are **controlled** with explicit echo suppression. Implement the three M4 automation stubs (`setValue`/`type`/`scroll`) as semantic actions on the UI thread. Ship `examples/gallery` (every M5b widget with live state + testIDs) driven headlessly by `scripts/headless-m5b.sh` + `scripts/m5b-drive.ts`, appended to CI. Make the conformance suite **actually** schema-driven (the M5a claim "new widgets get conformance for free" is currently false — verified: `src/conformance.zig:23-37` has a generic create loop but hardcoded per-widget assertions, and `src/null_backend.zig:68-87` is a hand-written 4-widget ladder — M5b fixes both).

**Architecture:** Unchanged two-process topology (D1). Three generalizations:
1. **Events:** the M4 event path is `GTK signal → gtk_backend.onClicked → event_sink(node_id) → runtime.sendEvent(hardcoded "clicked", empty payload)` (`src/gtk_backend.zig:31-40`, `src/runtime.zig:88-92`). M5b generalizes the sink to `(node_id, name, payload)`, moves ALL signal wiring into codegen output (`generated.connectEvents`, replacing the hand-written `connectButtonClick` + the Button special-case at `src/tree.zig:120-125`), and gives `protocol.Event.payload` a typed optional-fields struct serialized with `emit_null_optional_fields = false`.
2. **Containers:** structural ops (`appendChild`/`insertBefore`/`removeChild`) become kind-aware and move into codegen output too (Window/ScrollView = single-child `setChild`; Box = `append`; TabView = `appendPage` + per-child `tabLabel`; Grid = `attach` with per-child row/column attached props). Attached props travel on the child's create-op props, are stashed in `tree.NodeMeta`, and are passed to the backend at attach time.
3. **Renderer:** host-config's hardcoded `onClick` special case (four literal sites: `host-config.ts:49,51,127,135` + `renderer.ts:29`) generalizes to a generated event table (`widgetEvents`/`handlerPropNames` in `schema-meta.ts`).

**Tech Stack:** unchanged — Zig 0.16.0 exact, vendored zig-gobject at `vendor/gobject-bindings`, Bun 1.3.13, GTK4 4.22.4 (devshell), TypeScript strict, weston headless + `GSK_RENDERER=cairo` for display-dependent scripts, plain `zig build test` for conformance. `tools/codegen.ts` keeps zero npm deps.

### M5b decision record (owner-facing judgment calls, locked by this plan)

- **M5b-D1 — Attached props are declared by the container, typed onto every intrinsic, applied at attach time.** `container.attachedProps` in the schema declares props (e.g. Grid's `gridRow`/`gridColumn`/`gridRowSpan`/`gridColumnSpan`, TabView's `tabLabel`) that children set in their own JSX. Codegen adds the union of all containers' attached props as optional fields to EVERY intrinsic (any widget can be a Grid/TabView child; a `gridRow` on a non-Grid child is inert). On the wire they ride the child's create-op props (no protocol change); `tree.apply` extracts them into `NodeMeta.attached` (typed struct `protocol.Attached`) at create, and passes them to `backend.appendChild/insertBefore` at attach. **Attached props are attach-time-only in M5b** — updating `gridRow` after mount is a documented no-op (`docs/widgets.md` says so); revisit if a real app needs live re-attach.
- **M5b-D2 — Controlled two-way widgets with two-layer echo suppression.** TextInput/TextArea/Checkbox/Radio/Slider/Select are controlled: native change → Event up; React state → prop down. Suppression, applied ONLY in the prop-apply path (never in automation actions — their events must flow like user input): **(layer 1) value-equality guard** — generated `applyProps` reads the current native value and skips the set when equal (also prevents GtkEntry cursor reset on redundant `setText`); **(layer 2) signal-handler block** — `connectEvents` records the change-handler id per GObject (`gobject.signalHandlerBlock/Unblock`, verified gobject2.zig:5743/5781) and `applyProps` blocks it around any real programmatic set (a genuinely different value pushed by React must not echo back as a synthetic user event). Suppression is keyed per-object: the Entry itself, the TextView's **buffer**, the CheckButton, the Scale, the DropDown.
- **M5b-D3 — Radio grouping via a `group: string` prop.** GTK4 has no GtkRadioButton; radios are `GtkCheckButton` + `setGroup` (verified gtk4.zig:8673). The schema models this as a required create-only `group` string prop; the generated create body keeps a host-side map `group name → first CheckButton` and calls `setGroup(first)` for subsequent members. Group entries live for the process lifetime (arena — acceptable v1 leak, documented). Group-mate auto-untoggle emits `toggled {checked:false}` on the loser — that event flows to React (correct: the app's single source of truth decides).
- **M5b-D4 — TabView = GtkNotebook with a `tabLabel` attached prop (per M5b-D1) and a `selectedIndex` prop.** `selectedIndex` is `createAndUpdate` but the create body ignores it (pages don't exist yet at create — children attach afterwards); it takes effect via update ops (`setCurrentPage`). No tab-switch event in M5b (GtkNotebook `switch-page` exists; deferred until something needs it — documented in `docs/widgets.md`).
- **M5b-D5 — Signal wiring is codegen-emitted, table-driven (honors D6).** `tools/codegen.ts` gains a `SIGNALS` template table keyed `Widget.event` → `{gtk signal name, target object (widget|buffer), callback body, suppressible?}` and emits `generated.connectEvents(widget, kind, node_id)` + one `callconv(.c)` callback per shape. It **throws** on a schema event without a template (same fail-loud design as the existing prop-template throws at `tools/codegen.ts:165,184`). All M5b signals connect through the generic `gobject.signalConnectData` (verified gobject2.zig:5677 — returns the `c_ulong` handler id needed for blocking; uniform for plain signals, interface signals like Editable's `"changed"`, and property notifications like `"notify::selected"`). `gtk_backend.connectButtonClick` and its `onClicked` are **deleted**; Button's `clicked` moves into the generated table.
- **M5b-D6 — Event vocabulary + payloads.** Wire `Event.name` values (free strings on the wire — `protocol.zig:30` — no protocol version bump): `clicked`, `changed`, `activate`, `toggled`, `valueChanged`, `selectionChanged`. `Event.payload` becomes `protocol.EventPayload` — a struct of optional fields `{text, checked, value, index}` serialized with `emit_null_optional_fields = false` so `clicked` still wires as `"payload":{}` (byte-compatible with M4). Handler props: `onClick`, `onChanged`, `onActivate`, `onToggled`, `onValueChanged`, `onSelectionChanged`, typed per payload kind in the generated intrinsics.
- **M5b-D7 — WebView is a schema stub.** Entry present (`"stub": true`), TS intrinsic exists, but the GTK create template prints `ND_WARN WebView is a v1 stub (no webkitgtk); rendering placeholder label` and returns a Label. **Why:** webkitgtk is a ~1GB closure with its own process tree, ABI churn (4.0/4.1/6.0 soname splits), and no headless-CI story inside our weston harness — pulling it into the v1 flake for one widget contradicts the pinned-toolchain discipline. The schema slot ships now so the intrinsic/tree/automation contracts are stable when a real backend lands (spec §7's CEF/webview note).
- **M5b-D8 — Null backend becomes schema-driven at runtime; conformance becomes genuinely generic.** `null_backend.init(gpa, schema_json)` parses the schema (fed by the existing `build_options` injection, `build.zig:81-83`) and records props generically (`StringArrayHashMap` of canonical-stringified values), so a new schema entry is covered by conformance with **zero** null-backend edits. Defaults are asserted from the schema itself. The GTK-side default-materialization behavior stays pinned by the M3/M4/M5b headless scripts (real GTK), not by the null backend — the null backend pins the schema contract (prop round-trip, container ordering, event wiring), which is what "conformance for free" can honestly mean without generating N backends.
- **M5b-D9 (scope note) — automation `setValue` also covers TextArea.** The prompt's list is TextInput/Checkbox/Slider/Select; TextArea is added via `TextBuffer.setText` because it is the only way to exercise TextArea's `changed` event headlessly (no keyboard synthesis exists — spec §8), and it falls out of the same dispatch switch. Radio is covered by the Checkbox arm (same GtkCheckButton type).

## Schema format extensions (the contract — read before Task 2)

`schema/widgets.json` keeps `"schemaVersion": 1` — all changes are **additive** (new widgets, new prop types, new optional keys). Format deltas:

- `props[].type` gains `"float"` (TS `number`, Zig `f64` via new `propFloat`, accepts JSON integer or float) and `"stringList"` (TS `string[]`, Zig reads the `std.json.Value` array via new `propArray`).
- `events[]` entries gain `"payload": "none" | "text" | "checked" | "value" | "index"` (default `"none"`), driving both the TS handler type and the Zig payload extraction.
- `container` gains `"attachedProps": [ …prop objects… ]` (optional; only Grid and TabView use it in M5b). Attached props use the same prop-object shape; they are typed onto **every** intrinsic (M5b-D1) and never applied by `applyProps`.
- Widget objects gain optional `"stub": true` (WebView only) — documented in generated docs.

```zig
/// Typed event payload. Exactly one field is set per event name (see the
/// schema's events[].payload): changed/activate -> text, toggled -> checked,
/// valueChanged -> value, selectionChanged -> index, clicked -> none.
/// Serialized with emit_null_optional_fields=false, so clicked still wires
/// as "payload":{} — byte-compatible with M4.
pub const EventPayload = struct {
    text: ?[]const u8 = null,
    checked: ?bool = null,
    value: ?f64 = null,
    index: ?i64 = null,
};

pub const Event = struct {
    type: []const u8 = "event",
    seq: u64,
    priority: []const u8 = "discrete",
    nodeId: u32,
    name: []const u8, // clicked | changed | activate | toggled | valueChanged | selectionChanged
    payload: EventPayload = .{},
};

/// Container attach metadata, extracted host-side from a child's create-op
/// props (gridRow/gridColumn/gridRowSpan/gridColumnSpan/tabLabel — the
/// schema's container.attachedProps). Not a wire frame itself; it rides
/// inside create-op props and is stashed in tree.NodeMeta.
/// `tab_label` is NOT owned here — tree.putMeta dupes it.
pub const Attached = struct {
    grid_row: i64 = 0,
    grid_column: i64 = 0,
    grid_row_span: i64 = 1,
    grid_column_span: i64 = 1,
    tab_label: ?[]const u8 = null,

    pub fn fromProps(props: ?std.json.Value) Attached {
        var a = Attached{};

function tsTypeOf(p: { type: PropType; values?: string[] }): string {
  switch (p.type) {
    case "string": return "string";
    case "int": return "number";
    case "float": return "number";
    case "bool": return "boolean";
    case "stringList": return "string[]";
    case "enum": return (p.values ?? []).map((v) => JSON.stringify(v)).join(" | ");
  }
}

function tsHandlerType(e: Event): string {
  switch (e.payload ?? "none") {
    case "none": return "() => void";
    case "text": return "(e: { text: string }) => void";
    case "checked": return "(e: { checked: boolean }) => void";
    case "value": return "(e: { value: number }) => void";
    case "index": return "(e: { index: number }) => void";
  }
}

const SIGNALS: Record<string, SignalTemplate> = {
  "Button.clicked":          { signal: "clicked",          target: "widget", cb: "cbClicked",          suppress: false },
  "TextInput.changed":       { signal: "changed",          target: "widget", cb: "cbEditableChanged",  suppress: true },
  "TextInput.activate":      { signal: "activate",         target: "widget", cb: "cbEntryActivate",    suppress: false },
  "TextArea.changed":        { signal: "changed",          target: "buffer", cb: "cbBufferChanged",    suppress: true },
  "Checkbox.toggled":        { signal: "toggled",          target: "widget", cb: "cbCheckToggled",     suppress: true },
  "Radio.toggled":           { signal: "toggled",          target: "widget", cb: "cbCheckToggled",     suppress: true },
  "Select.selectionChanged": { signal: "notify::selected", target: "widget", cb: "cbDropDownSelected", suppress: true },
  "Slider.valueChanged":     { signal: "value-changed",    target: "widget", cb: "cbScaleValueChanged", suppress: true },
};

function genZigEvents(s: Schema): string {
  // 1) collect used callbacks (dedupe), 2) emit callback bodies, 3) emit connectEvents.
  const used = new Set<string>();
  for (const w of s.widgets) for (const e of w.events) {
    const key = `${w.name}.${e.name}`;
    const t = SIGNALS[key];
    if (!t) throw new Error(`no signal template for event ${key} — add one when introducing it`);
    used.add(t.cb);
  }
  let out = ZIG_CALLBACKS_PREAMBLE; // the callback bodies below, filtered by `used`
  out += "pub fn connectEvents(widget: *gtk.Widget, kind: []const u8, node_id: u32) void {\n";
  out += "    const data: ?*anyopaque = @ptrFromInt(@as(usize, node_id));\n";
  out += "    _ = data;\n"; // removed by codegen when the widget list is non-empty; keep emission simple: only emit for widgets with events
  let first = true;
  for (const w of s.widgets) {
    if (w.events.length === 0) continue;
    out += `    ${first ? "if" : "} else if"} (std.mem.eql(u8, kind, ${JSON.stringify(w.name)})) {\n`;
    first = false;
    for (const e of w.events) {
      const t = SIGNALS[`${w.name}.${e.name}`]!;
      const objExpr = t.target === "buffer"
        ? "asObject(gtk.TextView.getBuffer(@ptrCast(@alignCast(widget))))"
        : "asObject(widget)";
      out += `        const obj_${t.cb} = ${objExpr};\n`;
      out += `        const hid_${t.cb} = gobject.signalConnectData(obj_${t.cb}, ${JSON.stringify(t.signal)}, @ptrCast(&${t.cb}), data, null, .{});\n`;
      out += t.suppress ? `        noteSuppressible(obj_${t.cb}, hid_${t.cb});\n` : `        _ = hid_${t.cb};\n`;
    }
  }
  if (!first) out += "    }\n";
  out += "}\n\n";
  return out;
}

const protocol = @import("protocol.zig");

/// Schema-driven in-memory backend. init(gpa, schema_json) parses the widget
/// schema; createWidget/applyProps record canonical-stringified prop values
/// generically, so conformance covers every schema widget with no per-widget
/// code here. Structural ops honor the schema's container.childModel.
pub const Node = struct {
    kind: []const u8, // points into the parsed schema (stable until reset)
    props: std.StringArrayHashMapUnmanaged([]const u8) = .empty, // name -> canonical JSON string, gpa-owned
    text: ?[]const u8 = null,
    visible: bool = true,
    attached: protocol.Attached = .{},
    children: std.ArrayList(*Node) = .empty,
    events: std.ArrayList([]const u8) = .empty, // connected event names, schema order
};
pub const Widget = Node;

const WidgetDef = struct {
    name: []const u8,
    child_model: enum { none, single, multi },
    // events + props are read straight from the retained parsed schema Value.
    json: std.json.Value,
};

var gpa: std.mem.Allocator = undefined;
var parsed_schema: ?std.json.Parsed(std.json.Value) = null;
var defs: std.StringArrayHashMapUnmanaged(WidgetDef) = .empty;
pub var nodes: std.ArrayList(*Node) = .empty;
pub var last_window: ?*Node = null;

pub fn init(allocator: std.mem.Allocator, schema_json: []const u8) !void {
    gpa = allocator;
    parsed_schema = try std.json.parseFromSlice(std.json.Value, gpa, schema_json, .{});
    const widgets = parsed_schema.?.value.object.get("widgets").?.array;
    for (widgets.items) |w| {
        const name = w.object.get("name").?.string;
        const container = w.object.get("container").?;
        const cm: @FieldType(WidgetDef, "child_model") = if (container == .null)
            .none
        else if (std.mem.eql(u8, container.object.get("childModel").?.string, "single"))
            .single
        else
            .multi;
        try defs.put(gpa, name, .{ .name = name, .child_model = cm, .json = w });
    }
}

pub fn reset() void { /* free nodes' props values + lists, clear nodes/last_window; keep defs+schema */ }
pub fn deinitAll() void { /* reset() + defs.deinit + parsed_schema.deinit — call from test teardown */ }

fn canon(value: std.json.Value) ![]const u8 {
    return std.json.Stringify.valueAlloc(gpa, value, .{});
}

pub fn createWidget(_: *anyopaque, kind: []const u8, props: ?std.json.Value) !*Node {
    const def = defs.get(kind) orelse return error.UnknownWidget;
    const node = try gpa.create(Node);
    node.* = .{ .kind = def.name };
    // Record every schema-declared non-meta prop: explicit value, else schema default.
    const sprops = def.json.object.get("props").?.array;
    for (sprops.items) |sp| {
        const pname = sp.object.get("name").?.string;
        const applies = sp.object.get("appliesTo").?.string;
        if (std.mem.eql(u8, applies, "meta")) continue;
        if (props != null and props.? == .object) {
            if (props.?.object.get(pname)) |v| {
                try node.props.put(gpa, pname, try canon(v));
                continue;
            }
        }
        if (sp.object.get("default")) |d| try node.props.put(gpa, pname, try canon(d));
    }
    if (std.mem.eql(u8, kind, "Window")) last_window = node;
    try nodes.append(gpa, node);
    return node;
}

pub fn applyProps(widget: *Node, kind: []const u8, props: ?std.json.Value) void {
    const def = defs.get(kind) orelse return;
    const v = props orelse return;
    if (v != .object) return;
    const sprops = def.json.object.get("props").?.array;
    for (sprops.items) |sp| {
        const pname = sp.object.get("name").?.string;
        if (!std.mem.eql(u8, sp.object.get("appliesTo").?.string, "createAndUpdate")) continue;
        if (v.object.get(pname)) |pv| {
            const c = canon(pv) catch continue;
            if (widget.props.fetchPut(gpa, pname, c) catch null) |old| gpa.free(old.value);
        }
    }
}

pub fn connectEvents(node: *Node, kind: []const u8, node_id: u32) void {
    _ = node_id;
    const def = defs.get(kind) orelse return;
    const sevents = def.json.object.get("events").?.array;
    for (sevents.items) |se| {
        node.events.append(gpa, se.object.get("name").?.string) catch {};
    }
}

pub fn appendChild(parent: *Node, parent_kind: []const u8, child: *Node, attached: protocol.Attached) void {
    child.attached = attached;
    const def = defs.get(parent_kind) orelse return;
    if (def.child_model == .single) parent.children.clearRetainingCapacity();
    parent.children.append(gpa, child) catch {};
}

pub fn insertBefore(parent: *Node, parent_kind: []const u8, child: *Node, before: ?*Node, attached: protocol.Attached) void {
    child.attached = attached;
    const def = defs.get(parent_kind) orelse return;
    if (def.child_model == .single) {
        parent.children.clearRetainingCapacity();
        parent.children.append(gpa, child) catch {};
        return;
    }
    if (before) |b| {
        for (parent.children.items, 0..) |c, i| {
            if (c == b) { parent.children.insert(gpa, i, child) catch {}; return; }
        }
    }
    parent.children.append(gpa, child) catch {};
}

pub fn removeChild(parent: *Node, parent_kind: []const u8, child: *Node) void {
    _ = parent_kind;
    for (parent.children.items, 0..) |c, i| {
        if (c == child) { _ = parent.children.orderedRemove(i); return; }
    }
}

pub fn setText(widget: *Node, text: []const u8) void { widget.text = text; }
pub fn setVisible(widget: *Node, visible: bool) void { widget.visible = visible; }
pub fn setEventSink(_: *const fn (u32, []const u8, protocol.EventPayload) void) void {}
pub fn getWindow() ?*Node { return last_window; }

    if (std.mem.eql(u8, kind, "TextInput")) {
        if (v != .string) return jobInvalidParams(job, "value must be a string for TextInput");
        const z = job.gpa.dupeZ(u8, v.string) catch return;
        defer job.gpa.free(z);
        const editable: *gtk.Editable = @ptrCast(@alignCast(widget));
        gtk.Editable.setText(editable, z); // fires "changed" -> Event -> React (by design)
    } else if (std.mem.eql(u8, kind, "TextArea")) {
        if (v != .string) return jobInvalidParams(job, "value must be a string for TextArea");
        const z = job.gpa.dupeZ(u8, v.string) catch return;
        defer job.gpa.free(z);
        const view: *gtk.TextView = @ptrCast(@alignCast(widget));
        gtk.TextBuffer.setText(gtk.TextView.getBuffer(view), z, -1);
    } else if (std.mem.eql(u8, kind, "Checkbox") or std.mem.eql(u8, kind, "Radio")) {
        if (v != .bool) return jobInvalidParams(job, "value must be a bool for Checkbox/Radio");
        gtk.CheckButton.setActive(@ptrCast(@alignCast(widget)), @intFromBool(v.bool));
    } else if (std.mem.eql(u8, kind, "Slider")) {
        const num: f64 = switch (v) {
            .float => v.float,
            .integer => @floatFromInt(v.integer),
            else => return jobInvalidParams(job, "value must be a number for Slider"),
        };
        // GtkAdjustment-backed: Range.setValue drives the Scale's adjustment and
        // clamps to [min, max]; fires "value-changed".
        gtk.Range.setValue(@ptrCast(@alignCast(widget)), num);
    } else if (std.mem.eql(u8, kind, "Select")) {
        if (v != .integer) return jobInvalidParams(job, "value must be an integer index for Select");
        gtk.DropDown.setSelected(@ptrCast(@alignCast(widget)), @intCast(v.integer)); // fires notify::selected
    } else {
        return jobInvalidParams(job, "setValue unsupported for this widget type"); // data carries {type}
    }
    const result = .{ .ref = job.ref, .applied = true };
    job.result_json = std.json.Stringify.valueAlloc(job.gpa, result, .{}) catch null;
}
```
`jobInvalidParams` sets `job.err_code = -32602`, `err_msg`, and `err_data_json` (allocPrint `{"ref":N,"type":"..."}` — mirror the -32001 err_data style). **Casting note:** `*gtk.Widget` → `*gtk.Editable`/`*gtk.CheckButton`/`*gtk.Range`/`*gtk.DropDown` via `@ptrCast(@alignCast(...))` is safe here because the kind string proves the concrete type (same pattern as generated `applyProps`).
