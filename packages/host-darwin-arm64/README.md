# @nativedesktop/host-darwin-arm64

Prebuilt NativeDesktop AppKit host binary (`bin/nd-shell`) for macOS on Apple
silicon. Installed automatically as an optional dependency of
`@nativedesktop/host`; never depend on this package directly.

Built by the release workflow in
[FormalSnake/NativeDesktop](https://github.com/FormalSnake/NativeDesktop). MIT.
