# @nativedesktop/host-linux-x64

Prebuilt NativeDesktop GTK4/libadwaita host binary (`bin/nd-hello`) for x86_64
Linux. Installed automatically as an optional dependency of
`@nativedesktop/host`; never depend on this package directly.

The binary links GTK4 and libadwaita dynamically; see `docs/runtime-deps.md` in
the repository for the runtime library contract. Built by the release workflow
in [FormalSnake/NativeDesktop](https://github.com/FormalSnake/NativeDesktop).
MIT.
